ตั้งค่าการเชื่อมต่อ Google Sheets API

นำ URL ที่ได้จากการกด Deploy as Web App ใน Google Apps Script มาวางที่ช่องด้านล่าง เพื่อให้หน้านี้เชื่อมต่อและบันทึกข้อมูลลง Google Sheet โดยตรง

วิธีตั้งค่าใน Apps Script:
  1. เปิดไฟล์ Code.gs ใน Google Sheets -> Extensions -> Apps Script
  2. กดปุ่มสีน้ำเงิน Deploy > New deployment
  3. เลือกประเภท Web app
  4. Execute as: Me (บัญชีของคุณ)
  5. Who has access: Anyone (ทุกคน)
  6. คัดลอก Web App URL (ลงท้ายด้วย /exec) มาวางในช่องด้านล่าง
